🚀 SpendSense AI: Intelligent Financial Management
SpendSense AI is a cutting-edge, full-stack financial automation platform that leverages the power of Artificial Intelligence to make expense tracking effortless. Built with the MERN stack and integrated with Google’s Gemini 1.5 Flash, it transforms how users manage their money through natural language processing and smart analytics.

✨ Key Features
🤖 AI Quick-Parse: Add expenses using natural language. Type "850 for Pizza at Dominos yesterday" and let the AI automatically extract the amount, merchant, date, and category.
📊 Smart Analytics: Interactive visualizations including category distribution donuts and monthly trend lines built with Recharts.
💡 AI Spending Insights: Receive personalized financial advice and weekly spending summaries generated by Gemini AI.
🚨 Anomaly Detection: Statistical analysis to identify and flag unusual spending patterns, helping you stay on track.
🎯 Professional Budgeting: Set monthly limits and get real-time "Budget vs. Actual" comparisons with a sleek visual gauge.
🔐 Enterprise-Grade Security: JWT-based authentication with secure httpOnly cookie rotation and protected API routes.

💡 Why SpendSense?
Unlike traditional expense apps that require tedious manual entry, SpendSense AI acts as a Personal Financial Assistant. By combining the speed of the MERN stack with advanced LLM capabilities, it reduces the friction of logging transactions while providing actionable insights that help users save money.
