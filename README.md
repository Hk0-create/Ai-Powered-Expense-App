# SpendSense AI 🚀

A modern, AI-powered expense management platform built with the MERN stack.

## ✨ Features

- **🤖 AI Quick Parse**: Add transactions using natural language (e.g., "Lunch 500 at KFC").
- **📊 Interactive Dashboard**: Real-time spending visualization and KPI tracking.
- **🛡️ Secure Auth**: JWT-based authentication with secure cookie rotation.
- **💡 AI Insights**: Personalized financial advice generated by Gemini 1.5 Flash.
- **📈 Analytics**: Category breakdowns and monthly spending trends.
- **🎯 Budget Management**: Set limits and track spending against goals.

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Recharts.
- **Backend**: Node.js, Express, MongoDB, Mongoose.
- **AI**: Google Gemini 1.5 Flash API.
- **Icons**: Lucide React.

## 🚀 Getting Started

1. **Clone the repo**
2. **Install Dependencies**
   ```bash
   npm install
   # or
   npm run install-all
   ```
3. **Setup Environment Variables**
   Create a `.env` file in the `server` directory (see `.env.example`).
4. **Run the app**
   ```bash
   npm run dev
   ```
